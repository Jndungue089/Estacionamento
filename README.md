# Sistema de Estacionamento
Seja bem-vindo ao MeuPark, um sistema voltado para a gerência de um estacionamento, criado com regras de negócio simples e intuitivas, usando os conceitos de POO e aprimoramento de lógica computacional
## Para que foi criado?
A princípio, foi criado para propósitos educacionais, porém, agora é uma ambição do seu autor, torná-lo nalgo mais roubusto e mais completo
